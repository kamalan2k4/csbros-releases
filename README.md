# csbros downloads

Installers for **csbros companion**: a hero drops by your screen to remind you to drink water.

Get it from the website, with install guides for Windows and Mac: **https://csbros.in**

| System | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | `csbros-setup-<version>.exe` |
| macOS 12 or later (Intel or Apple Silicon) | `csbros-<version>-mac.dmg` |

Every version is under [Releases](../../releases).
